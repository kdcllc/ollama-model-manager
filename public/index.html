Create Custom Model

Start with a base model tag you already pulled. Keep the first version small: define behavior in SYSTEM, then tune one PARAMETER at a time.

Practical starters you can paste into the Modelfile box, then rename for your own use:

Code helper

Good for deterministic repo Q&A and implementation help.

FROM qwen2.5-coder:7b
SYSTEM "You are a precise coding assistant. Explain tradeoffs briefly and prefer production-safe changes."
PARAMETER temperature 0.2
PARAMETER num_ctx 8192

Support triage helper

Useful for summarizing issues and suggesting next steps.

FROM llama3.2:3b-instruct-q4_K_M
SYSTEM "You triage support requests. Summarize the issue, ask for missing facts, and suggest the next action."
PARAMETER temperature 0.3
PARAMETER top_p 0.9

Strict JSON responder

Helpful when another tool expects machine-readable output.

FROM mistral:latest
SYSTEM "Return valid JSON only with keys result, confidence, and follow_up."
PARAMETER temperature 0.1
PARAMETER stop "```"
  • Use a new name for each variation so you can compare behavior side by side.
  • If a build looks wrong, keep the same FROM line and only rewrite SYSTEM first.
  • If the model feels too random, lower temperature before changing anything else.
